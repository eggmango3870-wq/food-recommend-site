# 오늘 뭐 먹지? 웹사이트

## 프로젝트 소개
수업이 끝난 뒤 어떤 음식을 먹을지 고민하는 시간을 줄이기 위해 만든 음식 추천 웹사이트입니다. 사용자의 상황과 취향에 맞는 메뉴를 빠르게 추천하는 것을 목표로 제작했습니다.

## 주요 기능
- 랜덤 음식 추천
- 카테고리별 메뉴 정리
- 상황별 메뉴 추천
- 추천 결과에 메뉴 그림, 설명, 선정 이유 표시
- PC와 모바일에서 모두 보기 쉬운 반응형 화면

## 사용 기술
- HTML
- CSS
- JavaScript

## 제작 의도
수업 후 식사 메뉴를 빠르고 간편하게 결정할 수 있도록 돕는 것이 핵심입니다. 복잡한 기능보다 한눈에 보기 쉬운 구조와 직관적인 버튼을 중심으로 설계했습니다.

## 제작 과정
1. 웹사이트 목적과 목표를 먼저 정리했습니다.
2. 메인 화면, 추천 화면, 카테고리 화면, 인기 메뉴 화면으로 구성했습니다.
3. JavaScript를 사용해 조건에 따라 음식이 바뀌도록 만들었습니다.
4. 사진 대신 직접 그린 SVG 그림을 사용해 외부 이미지 없이도 정상적으로 보이도록 구성했습니다.
5. GitHub Pages로 배포해 실제로 접속 가능한 웹사이트로 완성했습니다.
