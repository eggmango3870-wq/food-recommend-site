# 오늘 뭐 먹지? 웹사이트

## 파일 구성
- index.html
- recommend.html
- categories.html
- popular.html
- style.css
- script.js

## 실행 방법
1. 위 파일들을 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 엽니다.
3. GitHub Pages로 배포한 뒤 결과보고서의 주소를 실제 주소로 바꿉니다.

## GitHub Pages 배포
1. GitHub에 새 저장소를 만듭니다.
2. 위 파일을 업로드합니다.
3. Settings → Pages → Deploy from branch
4. Branch를 `main` / root로 지정합니다.
5. 생성된 URL을 결과보고서에 적습니다.
